Quick project I made to impress my friends at the D&D table. They will need to solve this puzzle to open a hatch in the sewers to invade a forgotten hobgoblin dungeon.
Completely inspired by the first level of [NandGame](https://nandgame.com/).

### Toolset
Game programmed in C++ using [raylib](https://www.raylib.com/), built with CMake and made playable on HTML5 using [emscripten](https://emscripten.org/).

### Motivation
This web version was made because I wanted to figure out how to run a C++ program on a browser.

### Running the game
You can play the game at [itch.io](https://rochoso.itch.io/crystal-shard-gate)!

The file-loading parts of the C++ code need some tinkering to be compiled, as I couldn't figure out how to pass a relative file path as a compiler argument using CMake, so there's no compiling instructions. If you want to play the game locally, check out the [main repository](https://github.com/luis-rochoso/eberron-shard-gate)!

# Update
Ran the session and the players loved the puzzle! They managed to figure it out in 50 minutes and it took a lot of collaborative thinking. It was very fun!
